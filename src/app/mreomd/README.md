# /mreomd — тренажёр теоретического экзамена ПДД (Молдова)

Раздел полностью клиентский: вопросы лежат в статических файлах, прогресс
(ответы, избранное, списки, заметки, история экзаменов) хранится в
`localStorage` браузера (`lib/store.ts`), резервная копия — JSON-файл на
странице «Статистика».

| Путь | Что там |
|---|---|
| `/mreomd` | главная: категория, прогресс, режимы, темы |
| `/mreomd/practice` | тренировка: новые, ошибки, случайные, марафон, сложные, списки, темы, билеты |
| `/mreomd/exam` | пробный экзамен в формате ASP (24 / 30 мин / ≥22 или 30 / 38 мин / ≥27) |
| `/mreomd/questions` | поиск по вопросам (RU/RO, без диакритики, по заметкам) и фильтры |
| `/mreomd/saved` | избранное, свои списки, вопросы с заметками, ошибки |
| `/mreomd/signs` | справочник знаков (SVG) с режимом карточек |
| `/mreomd/stats` | статистика, история экзаменов, настройки, бэкап |
| `/mreomd/info` | как проходит экзамен, категории, официальные ссылки |

## Формат вопросов

База — массив `QUESTIONS` в `data/questions.ts` (тип `Question` в `lib/types.ts`),
данные — `data/questions.json`. Это официальная база ASP (RU + RO), её собирает
`python scripts/mreomd/fetch_autotest.py` из API auto-test.online: категория B —
общие вопросы с билетами 1–24, C/D/E/F — дополнительные вопросы с `veh`
(truck / bus / trailer / trolley). Ответы кэшируются в `scripts/mreomd/.cache/`,
`--refresh` перекачивает всё заново.

```ts
{
  id: "asp-0123",            // уникальный и постоянный — на него ссылаются прогресс и списки
  no: 123,                   // номер вопроса в официальной базе (необязательно)
  ticket: 7,                 // номер билета, если источник делит на билеты (необязательно)
  topic: "intersections",    // id темы из TOPICS в data/meta.ts
  veh: ["truck"],            // только если вопрос для конкретного транспорта; без поля — для всех категорий
  q: { ru: "…", ro: "…" },   // ro можно опустить — тогда показывается русский текст
  a: [{ ru: "…", ro: "…" }, …],
  c: 1,                      // индекс правильного ответа в a
  e: { ru: "…", ro: "…" },   // пояснение (необязательно)
  img: { kind: "image", src: "/mreomd/q/B123.webp" }, // картинка из public/, или { kind: "sign", id: "p-stop" }
}
```

Картинки вопросов кладутся в `public/mreomd/q/`.
